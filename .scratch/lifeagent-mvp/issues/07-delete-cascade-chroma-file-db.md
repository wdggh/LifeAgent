# 07: 删除级联：向量、文件、记录

**What to build:** 删除 Document 时按 向量 → 文件 → 数据库记录 的顺序清理；任一步失败保留记录并返回错误，可重试完成；删除后该文档内容不再可检索。

**Blocked by:** 05（摄取管线核心）

**Status:** resolved

- [ ] 删除成功的文档会清理其向量、磁盘文件与数据库记录
- [ ] 清理中途失败时请求返回 5xx 且文档记录仍在，可再次删除
- [ ] 各清理步骤幂等：重复删除不产生错误副作用
- [ ] 删除完成后，检索不会返回该文档的任何内容
- [ ] 删除其他用户的文档返回 404；未认证请求返回 401

## Answer

已实现并验证（commit 见下方）：

- DELETE 顺序固定为 Chroma（按 document_id）→ 磁盘文件 → DB 行；三步均幂等
- 任一步失败：记录日志、保留 DB 行、返回 500 DOCUMENT_DELETE_FAILED，可重复 DELETE 完成清理
- 删除成功后：向量清空、文件移除、记录删除；再次 DELETE 返回 404
- 跨用户删除 404 / 未认证 401（沿用既有归属规则）
- 测试：2 个级联用例 + 全套 52 passed
