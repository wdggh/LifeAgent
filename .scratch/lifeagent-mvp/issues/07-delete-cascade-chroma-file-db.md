# 07: 删除级联：向量、文件、记录

**What to build:** 删除 Document 时按 向量 → 文件 → 数据库记录 的顺序清理；任一步失败保留记录并返回错误，可重试完成；删除后该文档内容不再可检索。

**Blocked by:** 05（摄取管线核心）

**Status:** ready-for-agent

- [ ] 删除成功的文档会清理其向量、磁盘文件与数据库记录
- [ ] 清理中途失败时请求返回 5xx 且文档记录仍在，可再次删除
- [ ] 各清理步骤幂等：重复删除不产生错误副作用
- [ ] 删除完成后，检索不会返回该文档的任何内容
- [ ] 删除其他用户的文档返回 404；未认证请求返回 401
